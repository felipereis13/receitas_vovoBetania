# Receitas da vovó

Abra **index.html** no navegador. Funciona sem instalação e sem internet.
Para levar a outro computador, copie a pasta inteira.

- `index.html`: conteúdo e estrutura da página.
- `style.css`: cores, tamanhos e adaptação ao celular.
- `script.js`: busca, favoritos, marcações e temporizador.
- `dados.js`: receitas e páginas originais do livro (por isso é o arquivo maior).
- `imagens/`: foto do bolo e receita manuscrita.

O arquivo com o nome antigo também abre a página nova.
Favoritos e marcações ficam salvos no navegador utilizado.
Mantenha a página aberta durante o temporizador.
